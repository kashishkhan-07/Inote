 # 📝 iNotes — MERN Stack Notes Application

A clean, responsive, and modern fullstack Notes application built using the MERN stack (MongoDB, Express.js, React.js, Node.js) with Tailwind CSS.

## 🚀 Features
- ⚡ **Full CRUD Operations**: Create, Read, Update, and Delete notes.
- 🔍 **Live Search**: Instant client-side filtering by title or content.
- 📋 **One-Click Copy**: Copy note contents directly to clipboard.
- 🎨 **Modern UI**: Polished responsive cards, loading skeletons, and interactive modal dialogs.
- 🛡️ **Dual-layer Validation**: Data integrity verified on both React frontend and Express backend.

## 🛠️ Tech Stack
- **Frontend**: React.js, Vite, Tailwind CSS, Axios, Lucide React
- **Backend**: Node.js, Express.js, Mongoose, Cors, Dotenv
- **Database**: MongoDB (Atlas / Local)
